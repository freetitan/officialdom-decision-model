> **这份笔记本还没在 Kaggle 上实跑过**——先拿 `sample-qa.jsonl` 的 3 条样本跑通全流程，再放大到真实数据。

## 里面有什么

- `qwen2.5-7b-qlora-kaggle.ipynb`：训练笔记本。装 Unsloth → 读 `qa.jsonl` → QLoRA 微调 → 合并 LoRA → 导出 GGUF（Q4_K_M，约 4GB）。
- `sample-qa.jsonl`：3 条格式示例（军机处、奏折、科举），**只是格式示范，训之前要换成你自己的问答对**。
- 本 README：使用步骤与数据准备方法。

## 在 Kaggle 上跑（按 11-08 核实的额度）

1. Kaggle 新建 Notebook，Accelerator 选 **GPU T4 x2**（本周 GPU 30 小时全剩，单次会话最长 12 小时）。
2. 把本笔记本和你的 `qa.jsonl` 传进 Notebook（右侧 Add data / 上传文件）。
3. 从上往下运行。先只用样本文件跑通：确认能训、能合并、能导出 GGUF，再换真实数据。
4. 真实训练分批跑：30 小时额度分 3 次会话，每次断点续训（笔记本里开了 `save_steps`，从检查点恢复见第 6 节注释）。

## 数据怎么做（最关键的一步）

- **首选是指令微调**：把史料做成问答对，`{"instruction": ..., "input": ..., "output": ...}`，见 `sample-qa.jsonl`。
  例：“清代军机处和明代内阁有什么区别？”→ 一段有史实、有区分点的回答。
- **第一批目标 500–2,000 条**：覆盖官制沿革、奏折公文体、铨选考核、地方治理几个主题，先跑通、看效果，再扩量。
- **古典文献要先清洗**：断句、异体字归一、OCR 错字——脏数据直接训，模型学会的是错字和乱断句。
- **不要指望微调保证史实准确**：微调教的是行话、文体和官场逻辑，细节（人名、年份、制度细节）它会一本正经地编。查得准要另加 RAG：史料切块入库，问答时先检索原文再回答。两者组合最合适：微调管风格与路子，RAG 管史实出处。
- **Drive 空间**：你的 Google Drive 免费 15GB，已用约 3GB，还剩约 13GB（11-08 核实），史料在 13GB 以内不用升级；100GB 档是 $1.99/月，超了再考虑。

## 预期

- 单卡 T4（16GB）：QLoRA 可训 7B，13B 也能跑；全参数微调上限约 1B。
- T4 x2（32GB）：QLoRA 13B 很宽松；全参数约 2–3B。
- TPU v3-8（128GB）：全参数能摸到 7B，但要用 JAX / PyTorch XLA，折腾程度高。
- 导出：GGUF Q4_K_M 的 7B 约 4GB，可本地用 Ollama / LM Studio 跑，也可推到 Hugging Face Spaces 给别人试。

## 底座为什么是 Qwen2.5-7B

- 中文与文言强，Unsloth 官方支持，QLoRA 在 Kaggle 额度内跑得动，训完可直接导出 GGUF。
- 备选 Qwen3-8B，同一流程换模型名即可。先定一个跑通，别在选型上耗时间。
